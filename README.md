# Two-Stage Miller-Compensated CMOS Op-Amp

Design and simulation of a two-stage Miller-compensated CMOS operational
amplifier using Cadence Virtuoso, Spectre and the GPDK090 technology.

## Author

Le Phan Thanh Liem  
University of Science, VNU-HCM  
Faculty of Electronics and Telecommunications

## Contents

- Design procedure and transistor sizing
- DC operating-point verification
- Open-loop gain and phase margin
- Input common-mode range
- Output-voltage swing
- Slew rate and settling time
- CMRR and PSRR simulations
